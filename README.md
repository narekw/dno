# Часы судного дна

Одностраничный сайт со счётчиками, вероятность для которых раз в неделю
пересчитывает Gemini на основе свежих новостей.

## Структура

```
index.html      — сам сайт (читает data.json)
data.json       — текущие вероятности (перезаписывается автоматически)
scripts/update-data.mjs        — скрипт, который спрашивает Gemini
.github/workflows/weekly-update.yml  — расписание запуска скрипта
```

## Настройка (один раз)

1. **Получи бесплатный ключ Gemini API**
   Зайди на https://aistudio.google.com/apikey → Create API key.
   Бесплатного лимита с большим запасом хватает на один запрос в неделю.

2. **Создай репозиторий на GitHub** и загрузи туда все эти файлы,
   сохранив структуру папок (`.github/workflows/...` обязательно на своём месте).

3. **Добавь ключ в секреты репозитория**
   Repository → Settings → Secrets and variables → Actions → New repository secret
   Имя: `GEMINI_API_KEY`
   Значение: ключ, который ты получил на шаге 1.

4. **Включи GitHub Pages**
   Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root` → Save.
   Сайт откроется по адресу `https://твой-логин.github.io/название-репозитория/`.

5. **Проверь автообновление вручную**
   Вкладка Actions → Weekly data update → Run workflow.
   Если всё настроено верно, через минуту-две `data.json` в репозитории
   обновится новым коммитом, а сайт подхватит новые цифры при следующей загрузке.

## Дальше — ничего делать не нужно

Каждый понедельник в 06:00 UTC GitHub Actions сам:
1. запускает `scripts/update-data.mjs`;
2. тот спрашивает Gemini с включённым поиском по новостям за последние 7 дней;
3. записывает три новых процента и дату в `data.json`;
4. коммитит и пушит изменение — GitHub Pages обновляет сайт автоматически.

## Если хочется поменять расписание

В файле `.github/workflows/weekly-update.yml` строка

```
- cron: "0 6 * * 1"
```

задаёт «каждый понедельник в 06:00 UTC». Формат — обычный cron
(минута час день-месяца месяц день-недели).
